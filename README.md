# Тренажер | PRO

Тренажер для подготовки к сертификациям **Яндекс Директ (профессиональный уровень)**
и **Яндекс Метрика**. Статическая страница без сборки и зависимостей — открывается
двойным кликом по `index.html` или публикуется через GitHub Pages.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка страницы |
| `assets/styles.css` | оформление, тёмная и светлая темы |
| `assets/app.js` | вся логика тренажера |
| `data/direct.js` | база вопросов по Яндекс Директу (`db_direct_base`) |
| `data/metrica.js` | база вопросов по Яндекс Метрике (`db_metrica_base`) |
| `assets/img/` | скриншоты к вопросам и иконки приложения |
| `manifest.json` | описание веб-приложения для экрана «Домой» |

## Возможности

**Режим тренажера**

- проверка ответа сразу, с подсветкой верных и пропущенных вариантов;
- подсказка (вопрос с подсказкой не идёт в зачёт правильных);
- разбор ответа со ссылкой на справку Яндекса — почти у каждого вопроса;
- скриншоты к вопросам, где без них не ответить — открываются на весь экран по клику;
- поиск по тексту вопросов и вариантов ответа;
- панель прогресса: пройдено, верно, ошибок, подсказок;
- «Повторить ошибки» — новый проход только по вопросам, где были ошибки или подсказки;
- автосохранение прогресса в браузере (localStorage) + выгрузка/загрузка JSON-файлом.

**Режим экзамена**

- «Быстрый» — 20 вопросов за 20 минут, «Полный» — 60 вопросов за 60 минут;
- таймер, скрытые ответы, проходной балл 80%;
- после завершения — разбор ошибок списком и повопросный просмотр с верными ответами;
- экзамен не затирает прогресс тренажера.

**Режим «Шпаргалка»**

Быстрый поиск ответа, а не прохождение теста: вводите любое слово — из вопроса,
из варианта ответа или из разбора — и сразу видите верный ответ.

- поиск по всем 669 вопросам, включая старые без подтверждения;
- ищет по отдельным словам: несколько слов — значит, найдены все сразу;
- «ё» и регистр не важны, совпадения подсвечены в тексте;
- верный ответ виден сразу в карточке, разбор и неверные варианты — по клику;
- сначала показываются вопросы с подтверждённым ответом;
- если искомое есть в другом тесте, рядом со счётчиком появится ссылка-переход;
- открыть поиск с клавиатуры: <kbd>/</kbd> (или <kbd>.</kbd> в русской раскладке).

**С телефона**

- одна колонка: вопрос сразу под панелью прогресса, без длинной сетки сверху;
- кнопки «Проверить / Далее», подсказка и справка закреплены у нижнего края экрана;
- список всех вопросов свёрнут в кнопку «Все вопросы (12 / 538)»;
- свайп влево и вправо переключает вопросы, после перехода экран сам встаёт на начало вопроса;
- скриншот к вопросу открывается в полном размере — его можно двигать и масштабировать жестом;
- в экзамене таймер закреплён сверху и виден при прокрутке;
- шпаргалка работает так же: поиск сверху, карточки с ответом в одну колонку;
- страницу можно сохранить на экран «Домой» — откроется без адресной строки,
  как приложение (iOS: «Поделиться» → «На экран Домой», Android: меню → «Установить»).

**Горячие клавиши**

| Клавиша | Действие |
| --- | --- |
| `1`…`9` | выбрать вариант ответа |
| `Enter` | проверить ответ / перейти далее |
| `←` `→` | предыдущий / следующий вопрос |
| `H` | подсказка |
| `Esc` | закрыть скриншот |
| `/` | открыть поиск по ответам |

## Откуда взяты ответы

База по Директу собрана из двух источников и сверена между ними.

1. **Разборы на [monster-marketing.ru](https://monster-marketing.ru/otvety-sertifikaciya-yandex-direkt/)** —
   основной источник: 529 страниц, по одной на вопрос. На каждой — список вариантов
   с пометкой верных, разбор «почему так» и ссылки на справку Яндекса. Часть вопросов
   встречается с разными наборами ответов («другой набор вариантов») — такие наборы
   разобраны как отдельные вопросы.
2. **Файл «Директ Ответы 2026»** — верным считается вариант, выделенный полужирным.
   Использован для перекрёстной проверки.

Поле `v` показывает, насколько ответ подтверждён:

| `v` | Что значит | Сколько |
| --- | --- | --- |
| 2 | ответ совпал в обоих источниках | 216 |
| 1 | подтверждён одним источником, с разбором и ссылкой на справку | 322 |
| 0 | вопрос из старой базы, источником не подтверждён | 131 |

Всего **669 вопросов**. По умолчанию включён фильтр **«Только проверенные ответы»**:
в тренажере и экзамене участвуют 538 вопросов с `v` 1 или 2. Снимите галочку, чтобы
добавить остальные — там базовый уровень, Метрика, Excel и Коммандер.

### Расхождения между источниками

Из 261 вопроса, который нашёлся в обоих источниках, ответы совпали в 218. В 36 случаях
при одинаковом списке вариантов ответы разошлись: взят ответ с разбором и ссылкой на
справку, а расхождение дописано в поле `note` и показывается после проверки ответа.

Разборы иногда прямо поправляют распространённый файл ответов — например, про перезапуск
обучения стратегии или про то, когда задаётся ценность конверсии, а не цена. Это
объясняется со ссылкой на документацию, но означает и риск: если проверяющая система
экзамена всё ещё ждёт старый ответ, разбор будет с ней не согласен. Спорные вопросы
видно по тексту разбора — там написано, что именно отмечено в файле ответов.

### Скриншоты

Два вопроса по Директу без скриншота не решаются: отчёт в Мастере отчётов с прочерками
и статистика кампании по возрастным группам. Картинки вырезаны из файла ответов в
`assets/img/` и выводятся прямо в вопросе — по клику открываются на весь экран
(закрыть: клик мимо картинки или `Esc`).

В базе Метрики шесть вопросов тоже ссылаются на скриншоты, но самих картинок в
источнике нет. Эти вопросы помечены пояснением, что скриншот отсутствует.

## Формат вопроса

```js
{
    q: "Текст вопроса",
    o: ["Вариант 1", "Вариант 2", "Вариант 3"],
    c: [1],                       // индексы верных вариантов в массиве o
    v: 2,                         // 2 — оба источника, 1 — один, 0 — не подтверждён
    img: "assets/img/x.png",      // необязательно: скриншот к вопросу
    alt: "Описание скриншота",    // необязательно: подпись для доступности
    ref: "https://yandex.ru/…",   // необязательно: ссылка на справку
    note: "Пояснение"             // необязательно: пояснение или расхождение
}
```

Количество элементов в `c` определяет тип вопроса: один верный вариант — радиокнопки,
несколько — чекбоксы. Порядок вариантов в интерфейсе перемешивается, поэтому индексы
в `c` привязаны к исходному порядку в `o`.

## Как добавить или поправить вопрос

1. Отредактируйте нужный объект в `data/direct.js` или `data/metrica.js`.
2. Проверьте, что индексы в `c` указывают на верные варианты из `o`.
3. Проставьте `v`: 2 — если ответ подтверждён обоими источниками, 1 — одним, 0 — ничем.
4. Если к вопросу нужен скриншот — положите файл в `assets/img/` и укажите путь
   в поле `img` (и описание в `alt`).
5. Откройте `index.html` и убедитесь, что вопрос отображается и проверяется корректно.

Прогресс в браузере привязан к тексту вопроса и вариантов, поэтому после правки
формулировки прогресс по этому вопросу сбросится — это ожидаемо.
